# cram-lite

极简 **Cram** 多米诺棋（Domineering 的无方向限制变体）：8×8 棋盘，两名玩家轮流放一块 1×2 多米诺（横/竖皆可），无子可放者判负。

Python 3.10+，**纯标准库**（argparse / copy / random / sys），零依赖。

## 玩法

- 棋盘 8×8，`·` 空格、`■` 已占。
- 输入四个整数 `r1 c1 r2 c2` 放一块多米诺（两格必须正交相邻），`q` 退出。
- 轮到你但无子可放 → 你输。

## 用法

```bash
python3 -m cram_lite              # 人机/双人交互
python3 -m cram_lite --auto --games 10 --seed 42   # AI 对 AI 自动演示
```

## AI 说明

贪心 1 步前瞻：选择让对手后续走法数最少的走法，平局时按 `--seed` 随机。Cram 是"无子可走判负"的 impartial game，贪心只是演示，不做深层搜索。
